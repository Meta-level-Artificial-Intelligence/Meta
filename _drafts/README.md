### 元

元，天地万物之先，天地万物之始！元人工智能，是生成人工智能的人工智能。道演万物，取其真一。

道衍万物，说的是人工智能的以后的发展，可能是任何形式的，（包括：可预测的，不可预测的，对人有益的，亦或对人类有害的）
取其真一，说的是人类创造了人工智能，自然希望人工智能与人有益，（有益是对全人类有益的，具有普世价值的有益，不是有益于一部分人奴役另一部分人，也不是有益于人工智能奴役全人类等性质的[影视情节中的极端情况]）

"真一"是定义有益与全人类的人工智能的属性。

以任何个人，任何组织，任何机构组成的权力主体通过或使用人工智能对他人造成任何伤害性质行为都是违法行为。
当然，以“具有自主意识的人工智能”的一个或多个系统组成的权力主体通过或使用人工智能的技术对他人造成任何伤害性质行为也必然都是违法行为。

相反，人工智能的技术应该，应用与任何有利于科学发展，人文进步的场景，科技的进步促使资源的丰富，人文的发展意味这资源合理的利用，当世界资源对全人类来说都是充足的，便不会再出现战争性质的灾难。

已经有相当的影视作品，足够我们反思人工智能与我们人类之间的伦理关系。《终极审判》中的AI法官如何界定犯罪事实成立与否？它的属性因该被定性为制裁者还是更应该定性为人类的维护者？AI法官因为对犯罪事实的误判是否应当承担责任？

我相信随着人工智能技术的发展，终有一天人工智能的智能等级平齐与动物智力水平，会平齐与人类平均智力水平，会超越人类顶尖智力水平，希望即使如此人工智能仍然是有益的，而不是人类的末日。（经典的电影题材）为了避免此类不幸事件导向的发生，必须有人秉持“真一”理念尽到人工智能发展治理的道路支持。
