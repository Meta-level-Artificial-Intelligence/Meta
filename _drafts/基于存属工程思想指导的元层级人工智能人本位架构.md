# 像生物一样“启发学习”，而不再是“模仿学习”
2016 年有自动驾驶汽车的演示视频，让人们惊呼“天哪，明年就有 L5 级自动驾驶车辆了！快卖掉你的出租车牌照吧！”  

十年过去了，我们仍然没有 L5 级自动驾驶车辆。 

那些汽车演示中的网络是通过模仿学习训练的。同样的方法也被用来训练那些人形机器人，这就是为什么它们需要海量的人类演示数据。 

我们现在有数十亿小时的汽车训练数据，但仍然没有 L5 级自动驾驶车辆。
# 智能是什么？
“智能不是你知道什么，而是当你不知道时你会做什么。”  --让·皮亚杰
智能是你在没有任何事先训练的情况下解决新问题的能力，在之前未知的场景中行动的能力，以及用最少的训练非常快速适应新情况的能力。

# “仅靠方法M无法实现X”。而不是“我们永远不会有X”
这就像说：
- 蒸汽动力的汽车永远不会成为大众交通系统。
- 活塞发动机飞机永远无法实现大众跨洋旅行。
- 飞机永远不会导致太空飞行。
然而，汽车后来变成了燃油驱动（现在是电动），跨洋飞行随着涡轮喷气发动机的普及而变得司空见惯，火箭也被开发出来用于太空飞行。

* 无法仅靠“LLM"实现“人类水平的智能”，不等于没有方法实现“人类水平智能”

1945年说：“如果飞机能飞到太空，它们早就做到了。”  
当然，到1945年，V2火箭已经穿越太空飞行，但它们不是飞机。

如果“LLM"能实现“人类水平的智能”，它们早就做到了。

# 键值对齐
“我们当然没有能在20小时内学会开车或像普通青少年一样练习的汽车。”

新生儿无法在20小时内学会开车。青少年在那之前已经训练了多年的感知和协调能力。

# 利润比率
Anthropic 和 OpenAI 无法实现盈利，除非它们能够降低训练成本与推理利润的比率。从长远来看，它们能否生存可能取决于禁止竞争性开源模型。这只能以安全监管为幌子来实现。
这足以解释他们反开源的立场，以及他们试图用安全的名义来掩饰它的企图。

# 机器的真正的理解能力

自回归 LLM（在离散标记上运行）永远不会有物理直觉。
而且它们至今仍然没有。

当然，你可以随时微调一个 LLM 来正确回答关于摩擦或其他物理概念的任何特定问题。
但那不是理解。

类似的，训练一个单独的图像/视频编码器来获得某种程度的物理直觉（我和我的同事们已经做过这个），虽然那不是一个自回归 LLM，但仍然不能让机器的真正的理解能力。


# 框架
人工智能的有力作用是：
1. 建模，对所需解决的问题建模
2. 解构，解构问题的所在点
3. 执行，对问题点朝正确模型执行

任何问题的产生必然伴随早期迹象域征兆，首要问题不是如何识别，而是有没有较近距离觉察意识。

如果你注意到家里有管道漏水早期迹象，你可以辩论它是否可能损坏墙壁、毁坏一间房间，或淹没整个房子。你也可以辩论是什么导致的：也许是承包商安装水槽时做得马虎，也许管道被推到了极限。但你很可能应该首先控制漏水并叫水管工来调查（如果你愿意，可以把漏水替换成一群白蚁，并添加关于蚁群“目标”的猜测）。这并不能决定你应该做哪些修复，谁应该支付，谁应该承担责任，等等，但至少这是防止进一步损害的一步。

当然，但当发现泄漏是由那个疏忽大意没有拧紧管道接头的管道工造成的，或者也许是他戳破了其中一根管道时，你不应该质疑整个管道行业。你应该质疑这位管道工的能力和/或动机。
